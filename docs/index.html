Project #2 - Opportunity Atlas Analysis¶

Author: Mea Johnson Dataset: Harvard Opportunity Atlas - Social Capital (College)

Project Overview¶

This project explores the relationship between colleges' social capital and various socioeconomic factors using the Opportunity Atlas dataset. The goal is to understand how different colleges, counties, and socioeconomic variables affect students' social capital, volunteerism, and support systems. By analyzing these factors, I aim to provide actionable insights that could help policymakers, educators, and communities improve educational environments and promote social mobility.

I cleaned the dataset by:

  • Handling missing values in columns like mean_students_per_cohort, volunteering_rate_college, and others.

  • Dropping or filling missing values based on the percentage of missing data in each column.

  • Removed columns that were irrelevant or had too many missing values to be useful for analysis.

Question 6: How do volunteering_rate_college and support_ratio_college vary by ZIP code?¶

# Drop missing values
df_zip = df[['zip', 'volunteering_rate_college', 'support_ratio_college']].dropna()

# Calculate average volunteering and support ratio by ZIP
df_zip_avg = df_zip.groupby('zip').agg({
    'volunteering_rate_college': 'mean',
    'support_ratio_college': 'mean'
}).reset_index()

# Select top 10 ZIP codes by volunteering rate
top_zips = df_zip_avg.sort_values(by='volunteering_rate_college', ascending=False).head(10)

# Plotting
plt.figure(figsize=(12, 6))

x = top_zips['zip'].astype(str)
volunteering = top_zips['volunteering_rate_college']
support = top_zips['support_ratio_college']

bar_width = 0.4
x_indexes = range(len(x))

plt.bar(x_indexes, volunteering, width=bar_width, label='Volunteering Rate', color='mediumseagreen')
plt.bar([i + bar_width for i in x_indexes], support, width=bar_width, label='Support Ratio', color='steelblue')

plt.xlabel('ZIP Code')
plt.ylabel('Average Rate')
plt.title('Volunteering Rate and Support Ratio (Top 10 ZIP Codes)')
plt.xticks([i + bar_width / 2 for i in x_indexes], x, rotation=45)
plt.legend()
plt.tight_layout()
plt.show()

Question 7: What Factors best predict a college's volunteering rate?¶

  • I found that colleges with higher social capital (clustering_college) and better support ratios tend to have higher volunteering rates. This suggests that colleges with stronger social support systems encourage student civic engagement

# Select relevant numeric columns
numeric_cols = df.select_dtypes(include='number')

# Drop rows with missing volunteering_rate_college
corr_df = numeric_cols.dropna(subset=['volunteering_rate_college'])

# Calculate correlation matrix
correlations = corr_df.corr(numeric_only=True)['volunteering_rate_college'].sort_values(ascending=False)

# Drop self-correlation
correlations = correlations.drop('volunteering_rate_college')

# Plot top 10 most correlated features
top_corr = correlations.head(10)

plt.figure(figsize=(10, 6))
top_corr.plot(kind='barh', color='mediumseagreen')

🧾 Conclusion¶

The analysis highlights the key factors influencing social capital across different colleges and counties. Colleges with higher levels of social capital often have better volunteer rates, more diverse student bodies, and stronger community support systems. By understanding these dynamics, educators and policymakers can create more inclusive, supportive environments that encourage social mobility and improve educational outcomes for students of all socioeconomic backgrounds.
